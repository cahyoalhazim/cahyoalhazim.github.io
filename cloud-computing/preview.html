Alur Autentikasi JWT

1

User login/register via Gateway, Gateway forward ke Auth Service

2

Auth Service validasi & generate JWT token

3

Token dikembalikan ke client, disimpan di cookie HttpOnly

4

Setiap request ke Project Service membawa JWT untuk validasi role

Role-Based Access Control

Admin

User
