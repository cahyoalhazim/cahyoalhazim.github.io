Install Docker & Docker Compose

Update sistem dan install Docker beserta Docker Compose plugin.

# Update package index
sudo apt update && sudo apt upgrade -y

# Install dependencies
sudo apt install -y apt-transport-https ca-certificates curl gnupg lsb-release

# Add Docker GPG key
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg

# Add Docker repository
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# Install Docker Engine
sudo apt update && sudo apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin

# Add user to docker group (logout & login ulang)
sudo usermod -aG docker $USER

# Verify installation
docker --version && docker compose version

Clone repository project dari GitHub/GitLab ke direktori server.

# Buat direktori project
mkdir -p ~/microservices && cd ~/microservices

Konfigurasi Environment Variables

Buat file .env untuk setiap service. JANGAN hard-code credential!

# Auth Service .env
cd auth-service && cp .env.example .env
nano .env

# Isi konfigurasi berikut:
APP_NAME="AuthService"
APP_ENV=production
APP_KEY=base64:...
APP_DEBUG=false

DB_CONNECTION=mysql
DB_HOST=user-db
DB_PORT=3306
DB_DATABASE=user_db
DB_USERNAME=db_user
DB_PASSWORD=strong_password_here

JWT_SECRET=your_jwt_secret_key
JWT_TTL=60

Penting!

Gunakan password yang kuat dan unik. Jangan pernah commit file .env ke repository. Tambahkan .env ke .gitignore.

Docker Compose Configuration

Pastikan docker-compose.yml sudah terkonfigurasi dengan benar untuk production.

version: '3.8'

services:
  # Gateway / Frontend
  gateway:
    build: ./gateway
    container_name: gateway
    ports:
      - "80:80"
    depends_on:
      - auth-service
      - project-service
    networks:
      - microservices-network

  # Auth Service
  auth-service:
    build: ./auth-service
    container_name: auth-service
    ports:
      - "8001:8000"
    environment:
      - APP_ENV=production
    env_file:
      - ./auth-service/.env
    depends_on:
      - user-db
    networks:
      - microservices-network

  # Project Service
  project-service:
    build: ./project-service
    container_name: project-service
    ports:
      - "8002:8000"
    environment:
      - APP_ENV=production
    env_file:
      - ./project-service/.env
    depends_on:
      - project-db
    networks:
      - microservices-network

  # User Database
  user-db:
    image: mysql:8.0
    container_name: user-db
    environment:
      MYSQL_ROOT_PASSWORD: root_password
      MYSQL_DATABASE: user_db
    volumes:
      - user-db-data:/var/lib/mysql
    networks:
      - microservices-network

  # Project Database
  project-db:
    image: mysql:8.0
    container_name: project-db
    environment:
      MYSQL_ROOT_PASSWORD: root_password
      MYSQL_DATABASE: project_db
    volumes:
      - project-db-data:/var/lib/mysql
    networks:
      - microservices-network

volumes:
  user-db-data:
  project-db-data:

networks:
  microservices-network:
    driver: bridge

Build & Run Containers

Build image dan jalankan semua service dalam mode detached.

# Build dan jalankan semua service
docker compose up -d --build

# Cek status container
docker compose ps

# Cek logs jika ada error
docker compose logs -f [service_name]

# Jalankan migration (jika belum)
docker compose exec auth-service php artisan migrate --force
docker compose exec project-service php artisan migrate --force

# Generate JWT secret
docker compose exec auth-service php artisan jwt:secret

# Seed data awal (opsional)
docker compose exec auth-service php artisan db:seed

Konfigurasi Firewall & Reverse Proxy

Aktifkan UFW dan konfigurasi Nginx sebagai reverse proxy untuk production.

# Install UFW (Uncomplicated Firewall)
sudo apt install -y ufw

# Allow SSH, HTTP, HTTPS
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# Enable firewall
sudo ufw enable

# Install Nginx sebagai reverse proxy
sudo apt install -y nginx

# Konfigurasi Nginx (sederhana)
sudo nano /etc/nginx/sites-available/microservices

Contoh Konfigurasi Nginx:

server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://localhost:80;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

Troubleshooting Umum

Permission Denied saat docker command

Solusi: sudo usermod -aG docker $USER lalu logout & login ulang.

Port sudah digunakan

Solusi: sudo lsof -i :80 lalu kill process atau ganti port di docker-compose.yml.

Database connection refused

Solusi: Pastikan DB_HOST di .env menggunakan nama service container (bukan localhost).

JWT token invalid

Solusi: Pastikan JWT_SECRET sama di semua service yang membutuhkan validasi token.
