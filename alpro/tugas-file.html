Tujuan Pembelajaran

Setelah mengerjakan tugas ini, mahasiswa diharapkan mampu:

  • Memahami konsep sequential file dan cara kerjanya
  • Menggunakan struct untuk mendefinisikan tipe data rekaman
  • Melakukan operasi CRUD (Create, Read, Update, Delete) pada file
  • Menggunakan delimiter untuk memisahkan data dalam file
  • Memahami strategi rewrite file untuk Update dan Delete

Deskripsi Tugas

Buatlah program C++ untuk mengelola data Nilai Mahasiswa dengan spesifikasi berikut:

Satu mahasiswa dapat memiliki beberapa nilai (karena mengambil beberapa mata kuliah dalam satu semester).

Struktur Data (Struct)

struct NilaiMahasiswa { string nim; // Nomor Induk Mahasiswa string nama; // Nama Mahasiswa string kodeMatkul; // Kode Mata Kuliah string namaMatkul; // Nama Mata Kuliah float nilai; // Nilai (0 - 100) };

Format File CSV

NIM,Nama,KodeMatkul,NamaMatkul,Nilai 22001,Budi Santoso,IF101,Algoritma Pemrograman,85.5 22001,Budi Santoso,IF102,Struktur Data,78.0 22002,Ani Wijaya,IF101,Algoritma Pemrograman,90.0 22002,Ani Wijaya,IF103,Basis Data,88.5 22003,Caca Putri,IF101,Algoritma Pemrograman,75.0
Perhatian: Gunakan koma , sebagai delimiter. Pastikan tidak ada koma di dalam data (nama, matkul, dll)!

Fitur Wajib WAJIB

1
CREATE - Tambah Data Nilai
  • Input: NIM, Nama, Kode Matkul, Nama Matkul, Nilai
  • Simpan ke file nilai_mahasiswa.csv dengan format CSV
  • Gunakan mode ios::app agar data lama tidak hilang
  • Bisa input banyak data (loop sampai user selesai)
2
READ - Tampilkan Semua Data
  • Baca file nilai_mahasiswa.csv secara sequential
  • Split setiap baris menggunakan delimiter koma ,
  • Tampilkan dalam bentuk tabel yang rapi
  • Tampilkan nomor urut setiap baris
3
READ (Khusus) - Tampilkan per Mahasiswa + Rata-rata
  • Hitung rata-rata nilai setiap mahasiswa
  • Tampilkan: NIM, Nama, Jumlah Matkul, Rata-rata Nilai
  • Contoh: Budi Santoso mengambil 2 matkul, rata-rata = (85.5 + 78.0) / 2 = 81.75
4
UPDATE - Ubah Data
  • User memilih nomor baris yang akan diubah
  • Input data baru (semua field)
  • Strategi: baca file lama -> tulis file baru -> rename
  • Gunakan file temporary: nilai_temp.csv
5
DELETE - Hapus Data
  • User memilih nomor baris yang akan dihapus
  • Strategi: skip baris target saat rewrite file
  • Gunakan file temporary: nilai_temp.csv
  • Hapus file lama, rename file baru
6
Menu Utama
  • Tampilkan menu dengan pilihan 1-6
  • Loop sampai user memilih keluar
  • Setiap operasi menampilkan konfirmasi berhasil/gagal

Tips Pengerjaan TIPS

1
Header File yang Dibutuhkan

2
Rumus Split (Explode) dengan stringstream
string line = "22001,Budi,IF101,Algo,85.5"; stringstream ss(line); string nim, nama, kode, matkul, nilaiStr; getline(ss, nim, ','); // nim = "22001" getline(ss, nama, ','); // nama = "Budi" getline(ss, kode, ','); // kode = "IF101" getline(ss, matkul, ','); // matkul = "Algo" getline(ss, nilaiStr,','); // nilaiStr= "85.5" float nilai = stof(nilaiStr); // Konversi string -> float
3
Strategi Update/Delete (Rewrite File)
// UPDATE: ganti baris target dengan data baru // DELETE: skip baris target (tidak ditulis ke file baru) ifstream fileLama("nilai_mahasiswa.csv"); ofstream fileBaru("nilai_temp.csv"); // Copy header getline(fileLama, line); fileBaru << line << endl; // Baca dan proses setiap baris while (getline(fileLama, line)) { baris++; if (baris == targetBaris) { // UPDATE: tulis data baru // DELETE: skip (tidak tulis apa-apa) } else { fileBaru << line << endl; // Copy langsung } } fileLama.close(); fileBaru.close(); remove("nilai_mahasiswa.csv"); rename("nilai_temp.csv", "nilai_mahasiswa.csv");
4
Hitung Rata-rata per Mahasiswa
// Algoritma: // 1. Baca file sequential // 2. Simpan data ke array of struct // 3. Kelompokkan berdasarkan NIM // 4. Hitung total nilai / jumlah matkul // Pseudocode: sort array berdasarkan NIM // agar NIM sama berurutan for setiap data: if NIM sama dengan sebelumnya: total += nilai count++ else: // Cetak rata-rata mahasiswa sebelumnya rata = total / count // Reset untuk mahasiswa baru total = nilai count = 1
5
Format Tabel Rapi dengan setw
cout << left << setw(8) << "No" << setw(12) << "NIM" << setw(20) << "NAMA" << setw(10) << "KODE" << setw(25) << "MATA KULIAH" << setw(8) << "NILAI" << endl; cout << fixed << setprecision(2) << nilai; // 85.50
