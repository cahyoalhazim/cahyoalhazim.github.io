➕ 1. CREATE - Menambah Data

void createData() { ofstream file("data.csv", ios::app); // Mode append (tambah di akhir) Mahasiswa mhs; // Input dari user cout << "NIM : "; cin >> mhs.nim; cin.ignore(); cout << "Nama : "; getline(cin, mhs.nama); cout << "Nilai : "; cin >> mhs.nilai; // Tulis ke file dengan format CSV file << mhs.nim << "," << mhs.nama << "," << mhs.nilai << endl; file.close(); cout << "Data berhasil ditambahkan!"; }
Mode File:
  • ios::out = Hapus file lama, buat baru (OVERWRITE)
  • ios::app = Tambah di akhir file (APPEND) ← Pakai ini!
Perhatian: Kalau pakai ios::out, data lama akan hilang! Untuk menambah data baru, selalu pakai ios::app.

📖 2. READ - Membaca & Menampilkan Data

void readData() { ifstream file("data.csv"); string line, nim, nama, nilaiStr; if (!file) { cout << "File tidak ditemukan!"; return; } // Lewati header (baris pertama) getline(file, line); cout << "No. NIM NAMA NILAI" << endl; cout << "----------------------------------------" << endl; int no = 1; while (getline(file, line)) { // Baca per baris sampai EOF stringstream ss(line); // Ubah string jadi stream // SPLIT dengan delimiter ',' getline(ss, nim, ','); // Ambil sampai koma -> NIM getline(ss, nama, ','); // Ambil sampai koma -> Nama getline(ss, nilaiStr); // Sisa sampai akhir -> Nilai cout << no << " " << nim << " " << nama << " " << nilaiStr << endl; no++; } file.close(); }
getline dengan 3 parameter:
getline(stream, variabel, delimiter); // stream = sumber data (stringstream) // variabel = tempat menyimpan hasil // delimiter = karakter pemisah (',')
Salah:
Mustahil split string dengan delimiter di C++ native
Benar:
Simpel, fleksibel, delimiter bebas diganti!
// Baris CSV: 22001,Budi Santoso,85.5 // ^ ^ ^ // koma1 koma2 akhir stringstream ss("22001,Budi Santoso,85.5"); getline(ss, nim, ','); // nim = "22001" getline(ss, nama, ','); // nama = "Budi Santoso" getline(ss, nilai, ','); // nilai = "85.5" // Hasil: 3 variabel terpisah dari 1 baris!

✏️ 3. UPDATE - Mengubah Data

void updateData(int nomorBaris) { ifstream fileLama("data.csv"); ofstream fileBaru("data_temp.csv"); string line, nim, nama, nilaiStr; int baris = 0; // Baca header getline(fileLama, line); fileBaru << line << endl; baris++; while (getline(fileLama, line)) { baris++; if (baris == nomorBaris) { // Baris ini di-UPDATE fileBaru << "22001,Budi UPDATE,95.0" << endl; } else { // Baris ini tetap (copy) fileBaru << line << endl; } } fileLama.close(); fileBaru.close(); // Ganti file lama dengan file baru remove("data.csv"); rename("data_temp.csv", "data.csv"); cout << "Data berhasil diupdate!"; }
Penting: Sequential file TIDAK BISA edit di tengah! Harus rewrite seluruh file.
Strategi Update:
  1. Baca file lama baris per baris
  2. Tulis ke file baru
  3. Baris yang diupdate -> tulis data baru
  4. Baris lain -> copy langsung
  5. Hapus file lama, rename file baru

🗑️ 4. DELETE - Menghapus Data

void deleteData(int nomorBaris) { ifstream fileLama("data.csv"); ofstream fileBaru("data_temp.csv"); string line; int baris = 0; // Baca header getline(fileLama, line); fileBaru << line << endl; baris++; while (getline(fileLama, line)) { baris++; if (baris != nomorBaris) { // Baris ini tetap (bukan yang dihapus) fileBaru << line << endl; } // Kalau baris == nomorBaris -> SKIP (tidak ditulis) } fileLama.close(); fileBaru.close(); remove("data.csv"); rename("data_temp.csv", "data.csv"); cout << "Data berhasil dihapus!"; }
Sama seperti Update: Tidak bisa hapus langsung. Strateginya SKIP baris yang dihapus saat rewrite.
Salah:
Hapus baris di tengah file
-> Corrupt! Sequential tidak bisa!
Benar:
Copy semua kecuali baris target
-> File baru tanpa baris tersebut

#include <iostream> #include <fstream> #include <sstream> #include <string> #include <iomanip> using namespace std; struct Mahasiswa { string nim = ""; string nama = ""; float nilai = 0.0; }; // Fungsi-fungsi CRUD void create(); void read(); void update(); void hapus(); int main() { int pilihan; do { cout << " ========== MENU ==========" << endl; cout << "1. 💡 Tips & Best Practices

1
Selalu tutup file dengan file.close() setelah operasi selesai.
2
Cek file berhasil dibuka dengan if (!file) sebelum operasi.
3
Pakai cin.ignore() setelah cin >> sebelum getline() untuk membersihkan buffer.
4
Header CSV selalu tulis di baris pertama untuk dokumentasi.
5
Backup file sebelum operasi Update/Delete yang berisiko.
