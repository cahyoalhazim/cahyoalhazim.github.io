TUGAS AKHIR SEMESTER
ALGORITMA PEMROGRAMAN C++

Mahasiswa diminta membuat project kelompok menggunakan bahasa pemrograman C++. Project wajib menerapkan konsep:

  • Perulangan (for / while)
  • Searching
  • Sorting
  • Function / Procedure
  • File Handling (simpan & baca file)
Catatan:
Setiap kelompok wajib memilih 1 topik project di bawah ini dan melakukan presentasi pada akhir semester.

Daftar Topik Project

1. Sistem Manajemen Perpustakaan

  • Tambah buku
  • Peminjaman buku
