Kesehatan

Prediksi risiko penyakit jantung berdasarkan profil pasien

Sumber data — UCI Heart Disease · Kaggle Heart Failure Prediction

Logistic Regression Random Forest XGBoost SVM ROC-AUC SHAP Confusion Matrix

Analisis data medis pasien untuk memprediksi risiko penyakit jantung menggunakan model klasifikasi. Bandingkan performa model linear (Logistic Regression) dengan model tree-based (Random Forest, XGBoost) dan kernel-based (SVM). Gunakan SHAP untuk menjelaskan faktor risiko utama secara medis.

Dataset

UCI Heart Disease

kaggle.com/datasets/uciml/heart-disease-dataset

Heart Failure Prediction

kaggle.com/datasets/fedesoriano/heart-failure-prediction

Langkah pengerjaan

  1. 01Load data, identifikasi missing value, encode variabel kategorikal (ChestPainType, RestingECG, ST_Slope)
  2. 02EDA: distribusi target, korelasi fitur, outlier detection pada Cholesterol dan MaxHR
  3. 03Split data (stratified), scaling dengan StandardScaler, handle class imbalance dengan SMOTE
  4. 04Training 4 model: Logistic Regression, Random Forest, XGBoost, SVM — gunakan 5-fold CV
  5. 05Hyperparameter tuning (GridSearchCV) untuk 2 model terbaik, analisis ROC-AUC dan Precision-Recall
  6. 06SHAP summary plot untuk interpretasi feature importance secara medis

Hint teknis

  • Fitur Cholesterol memiliki nilai 0 yang merupakan missing value terselubung — ganti dengan median
  • Gunakan StratifiedKFold agar proporsi target tetap seimbang di setiap fold
  • Bandingkan ROC-AUC dengan Average Precision — untuk data imbalance, AP lebih informatif
  • SHAP waterfall plot untuk 1 sampel pasien sangat powerful untuk menjelaskan prediksi ke dokter

Pertanyaan analisis

Q1

Model manakah yang paling optimal untuk prediksi risiko jantung? Bandingkan ROC-AUC, Precision, Recall, dan F1-Score. Jelaskan trade-off antara sensitivity dan specificity.

Q2

Fitur apa saja yang paling berpengaruh terhadap risiko penyakit jantung? Gunakan SHAP values untuk mengidentifikasi top 5 fitur. Jelaskan hubungannya secara medis.

Q3

Bagaimana model ini bisa digunakan dalam praktik klinis? Berapa threshold optimal untuk meminimalkan pasien sakit yang terlewat? Berapa biaya false positive vs false negative?

Q4

Apakah ada bias gender atau usia dalam prediksi model? Analisis performa model per kelompok demografi. Apakah model lebih akurat untuk pria dibanding wanita?

Q5

Rekomendasi screening apa yang dapat disimpulkan? Berdasarkan feature importance dan threshold optimal, siapa yang harus diprioritaskan untuk pemeriksaan jantung preventif?

Properti

Prediksi harga rumah berdasarkan karakteristik properti

Sumber data — Kaggle House Prices: Advanced Regression Techniques

Linear Regression Ridge / Lasso Random Forest Regressor XGBoost Regressor RMSE / R² Feature Engineering Cross-Validation

Analisis data properti Ames, Iowa untuk memprediksi harga jual rumah menggunakan model regresi. Lakukan feature engineering intensif — buat fitur baru dari kombinasi fitur eksisting. Bandingkan model linear regularized dengan ensemble methods. Evaluasi dengan RMSE dan R².

Dataset

House Prices: Advanced Regression

kaggle.com/c/house-prices-advanced-regression-techniques/data

Langkah pengerjaan

  1. 01Load data train+test, analisis missing value pattern, identifikasi fitur kategorikal vs numerik
  2. 02Feature engineering: TotalSF, HouseAge, RemodAge, TotalBath, HasPool, Has2ndFloor
  3. 03Imputasi missing value, encoding, log-transform target (SalePrice)
  4. 04Training 4 model: Linear Regression, Ridge, Lasso, Random Forest, XGBoost Regressor
  5. 05Hyperparameter tuning: alpha untuk Ridge/Lasso, n_estimators + max_depth untuk tree-based
  6. 06Analisis residual plot, identifikasi overfitting, feature importance dari model terbaik

Hint teknis

  • SalePrice sangat right-skewed — gunakan np.log1p() sebelum training, inverse transform saat evaluasi
  • Lasso Regression bisa digunakan untuk feature selection — fitur dengan coef = 0 bisa di-drop
  • Buat interaction feature seperti OverallQual × GrLivArea — kualitas dan ukuran saling memperkuat
  • Residual plot harus menunjukkan pola acak; jika ada pola berarti model masih miss sesuatu

Pertanyaan analisis

Q1

Model regresi manakah yang paling akurat memprediksi harga rumah? Bandingkan RMSE, MAE, dan R². Jelaskan mengapa model tertentu unggul.

Q2

Fitur buatan (engineered) mana yang paling meningkatkan performa model? Bandingkan skor sebelum dan sesudah feature engineering.

Q3

Apakah regularization (Ridge/Lasso) membantu mengurangi overfitting? Bandingkan train score vs test score. Berapa alpha optimal?

Q4

Di neighborhood mana rumah paling overpriced/underpriced? Analisis residual per neighborhood — rumah mana yang model prediksi terlalu rendah/tinggi?

Q5

Rekomendasi investasi properti berbasis model? Jika Anda memiliki budget $200,000, neighborhood dan karakteristik rumah seperti apa yang memberikan value terbaik?

Industri

Klasifikasi kualitas anggur merah berdasarkan sifat kimiawi

Sumber data — UCI Wine Quality · Kaggle Red Wine Quality

Logistic Regression Decision Tree Random Forest Gradient Boosting KNN SMOTE Classification Report

Analisis data kimiawi anggur merah untuk mengklasifikasikan kualitasnya (3–8) atau binary (good/bad). Dataset relatif bersih dengan 11 fitur numerik, cocok untuk memahami trade-off antar model secara mendalam. Eksplorasi multi-class vs binary classification.

Dataset

Red Wine Quality

kaggle.com/datasets/uciml/red-wine-quality-cortez-et-al-2009

Langkah pengerjaan

  1. 01Load data, cek duplikat, analisis distribusi target (quality) — identifikasi class imbalance
  2. 02EDA: korelasi antar fitur kimiawi, scatter plot (alcohol vs quality, volatile acidity vs quality)
  3. 03Buat 2 target: (a) multi-class (quality 3–8), (b) binary (quality ≥ 7 = good, < 7 = bad)
  4. 04Training 5 model: Logistic Regression, Decision Tree, Random Forest, Gradient Boosting, KNN
  5. 05Evaluasi per target: accuracy, precision, recall, F1 per kelas — bandingkan multi-class vs binary
  6. 06Feature importance analysis: alcohol, volatile acidity, sulphates — validasi dengan domain knowledge

Hint teknis

  • Dataset kecil (1,599 baris) — gunakan StratifiedKFold dengan k=10 untuk estimasi performa yang lebih stabil
  • volatile acidity dan alcohol adalah 2 fitur paling prediktif — pastikan EDA menyorot keduanya
  • Untuk multi-class, perhatikan kelas 3, 4, dan 8 yang sangat jarang — SMOTE atau class weight bisa membantu
  • Decision Tree tanpa pruning akan overfit — bandingkan dengan max_depth yang dibatasi

Pertanyaan analisis

Q1

Apakah klasifikasi binary lebih akurat daripada multi-class? Bandingkan F1-Score macro untuk kedua pendekatan. Jelaskan mengapa satu pendekatan lebih baik dari segi praktis.

Q2

Fitur kimiawi mana yang paling membedakan anggur berkualitas tinggi vs rendah? Gunakan feature importance dan analisis statistik. Apakah hasilnya sesuai dengan pengetahuan enologi?

Q3

Model mana yang paling robust terhadap class imbalance? Bandingkan performa model dengan dan tanpa SMOTE/class weights. Model mana yang paling tidak terpengaruh imbalance?

Q4

Apakah ada fitur yang berkorelasi tinggi sehingga redundant? Analisis multicollinearity — apakah semua 11 fitur perlu digunakan?

Q5

Rekomendasi untuk pabrik anggur? Berdasarkan model, sifat kimiawi seperti apa yang harus dioptimalkan untuk meningkatkan kualitas anggur?

Telekomunikasi

Prediksi churn pelanggan telekomunikasi

Sumber data — Kaggle Telco Customer Churn

Logistic Regression Decision Tree Random Forest XGBoost SMOTE Threshold Tuning Cost-Benefit Analysis

Analisis data pelanggan layanan telekomunikasi untuk memprediksi churn (berhenti berlangganan). Fokus pada data imbalance (churn ~27%), feature engineering dari tenure, dan cost-benefit analysis untuk menentukan threshold prediksi yang optimal secara bisnis.

Dataset

Telco Customer Churn

kaggle.com/datasets/blastchar/telco-customer-churn

Langkah pengerjaan

  1. 01Load data, konversi TotalCharges ke numerik (ada string kosong), handle missing value
  2. 02EDA: churn rate per kategori (SeniorCitizen, Contract, InternetService), tenure distribution
  3. 03Feature engineering: tenure_group, avg_monthly_charge, num_services, is_new_customer
  4. 04Encoding kategorikal, scaling numerik, handle imbalance dengan SMOTE atau class_weight
  5. 05Training 4 model: Logistic Regression, Decision Tree, Random Forest, XGBoost — 5-fold CV
  6. 06Threshold tuning: cari threshold yang memaksimalkan profit (cost of retention vs cost of losing customer)

Hint teknis

  • Tenure adalah fitur paling prediktif — pelanggan baru (< 12 bulan) churn rate jauh lebih tinggi
  • Contract Month-to-Month memiliki churn rate ~40% vs Two-Year < 5% — fitur krusial
  • Gunakan Precision-Recall Curve untuk memilih threshold optimal, bukan hanya default 0.5
  • Cost-benefit: asumsikan biaya retention = $50, revenue loss churn = $500 — hitung expected profit per threshold

Pertanyaan analisis

Q1

Model mana yang paling baik untuk meminimalkan churn yang terlewat? Fokus pada Recall untuk kelas churn. Berapa threshold optimal jika biaya kehilangan pelanggan 10x lebih mahal dari biaya retention?

Q2

Profil pelanggan mana yang paling berisiko churn? Identifikasi segmen berdasarkan kombinasi fitur (tenure, contract, monthly charges). Buat persona pelanggan berisiko tinggi.

Q3

Apakah fitur engineered (tenure_group, avg_monthly_charge) meningkatkan performa? Bandingkan skor model dengan dan tanpa fitur buatan. Fitur mana yang paling berdampak?

Q4

Bagaimana hasil model berubah jika tidak menggunakan SMOTE? Analisis dampak class imbalance handling pada precision dan recall. Apakah SMOTE selalu membantu?

Q5

Rekomendasi strategi retensi berbasis model? Jika perusahaan memiliki budget $10,000 untuk program retensi, pelanggan mana yang harus diprioritaskan? Hitung expected ROI.

Pendidikan

Prediksi kelulusan mahasiswa berdasarkan data akademik

Sumber data — Kaggle Predict Students' Dropout and Academic Success

Logistic Regression SVM Random Forest XGBoost Neural Network (MLP) Feature Selection Learning Curve

Analisis data akademik mahasiswa untuk memprediksi apakah mereka akan dropout, graduate, atau masih enrolled. Tantangan utama adalah multi-class classification dengan class imbalance dan fitur yang sangat banyak (36 fitur). Fokus pada early warning system untuk intervensi akademik.

Dataset

Predict Students' Dropout and Academic Success

kaggle.com/datasets/thedevastator/higher-education-predictors-of-student-retention

Langkah pengerjaan

  1. 01Load data, cek missing value, analisis distribusi 3 kelas target (Graduate, Dropout, Enrolled)
  2. 02EDA: churn rate per fakultas, per semester, korelasi antara GPA semester awal dan outcome akhir
  3. 03Feature selection: gunakan mutual information atau RFE untuk mengurangi 36 fitur ke 15-20 fitur paling penting
  4. 04Training 5 model: Logistic Regression, SVM, Random Forest, XGBoost, MLP (Neural Network)
  5. 05Evaluasi multi-class: accuracy, F1-macro, F1-weighted, confusion matrix per kelas
  6. 06Learning curve analysis: apakah model underfit atau overfit? Butuh lebih banyak data atau lebih sedikit fitur?

Hint teknis

  • Curricular units 1st sem (approved) dan 2nd sem (approved) adalah fitur paling prediktif — GPA semester awal sangat menentukan
  • Kelas Enrolled bisa di-exclude untuk binary classification (Graduate vs Dropout) jika terlalu sulit
  • Gunakan learning_curve dari sklearn untuk memvisualisasikan apakah model masih bisa improve dengan lebih banyak data
  • MLPClassifier dengan 1-2 hidden layer cukup — jangan terlalu dalam karena dataset hanya ~4,000 baris

Pertanyaan analisis

Q1

Model mana yang paling akurat memprediksi dropout mahasiswa? Bandingkan F1-Score untuk kelas Dropout secara spesifik. Mengapa kelas ini paling penting untuk diprediksi dengan benar?

Q2

Fitur akademik semester ke-1 mana yang paling menentukan kelulusan? Analisis feature importance semester demi semester. Kapan intervensi paling efektif dilakukan?

Q3

Apakah Neural Network (MLP) lebih baik dari model tradisional untuk dataset ini? Bandingkan performa dan waktu training. Apakah kompleksitas tambahan sepadan?

Q4

Bagaimana performa model jika hanya menggunakan data semester 1? Simulasikan early warning system — apakah model cukup akurat untuk mendeteksi dropout sejak semester awal?

Q5

Rekomendasi sistem early warning untuk universitas? Berdasarkan model, buat dashboard kriteria mahasiswa berisiko dropout. Program bimbingan seperti apa yang paling efektif untuk setiap segmen risiko?
