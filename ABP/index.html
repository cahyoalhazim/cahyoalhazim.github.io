03 - Timeline

Roadmap 2 Pekan (14 Hari)

Kerjakan secara intensif dalam 2 pekan. Setiap pekan memiliki milestone harian yang harus dicapai. Progress tracking harian wajib dilaporkan.

Pekan 1 - Hari 1-2: Setup & Auth

🚀 Project Setup & Firebase Authentication

Inisialisasi project, konfigurasi Firebase, dan implementasi authentication flow lengkap.

  • Hari 1: Setup Flutter project dengan Clean Architecture folder structure. Konfigurasi Firebase (Auth, Firestore, Storage, FCM). Custom ThemeData Deep Navy & Safety Orange. Splash Screen & Login Screen UI.
  • Hari 2: Firebase Auth integration (email/NIK + password). "Remember Me" dengan SharedPreferences. Auth state listener. Forgot Password flow. Role-based access (Employee/Admin) di Firestore. Dashboard UI skeleton.
Deliverable Pekan 1: Demo login/logout, auth flow, dan dashboard skeleton. Submit ke Git dengan commit log harian.
Pekan 1 - Hari 3-5: GPS & Maps

📍 GPS Validation & Google Maps Integration

Implementasi real-time GPS tracking, perhitungan jarak, dan validasi radius kantor.

  • Hari 3: Integrasi Google Maps SDK. GPS tracking real-time dengan geolocator. Tampilkan user location dan kantor marker di peta.
  • Hari 4: Implementasi Haversine Formula untuk hitung jarak. Validasi radius 500m. Status indicator "In Area" (🟢) / "Outside Area" (🔴). Geofencing enter/exit detection.
  • Hari 5: Clock-in/out flow dengan GPS validation. Simpan attendance record ke Firestore (timestamp, location, status). Weekly stats calculation di Dashboard.
Pekan 1 - Hari 6-7: Face Detection

🤳 AI Face Detection & Selfie Capture

Camera integration dengan ML Kit untuk validasi wajah sebelum absensi.

  • Hari 6: Integrasi camera plugin untuk preview & capture. ML Kit Face Detection setup. Alignment frame overlay. Validasi: 1 wajah terdeteksi, tolak multiple faces.
  • Hari 7: Blur detection (sharpness analysis). Lighting indicator. Success/Failed screen UI. Upload selfie ke Firebase Storage: /attendance/{userId}/{date}.jpg. Integrasi face validation ke clock-in flow.
Checkpoint Pekan 1: Demo end-to-end: Login → GPS Check → Face Capture → Clock In → Save to Firebase. Wajib demo ke dosen/asisten.
Pekan 2 - Hari 8-9: History & Profile

📋 Attendance History, Notifications & Profile

Lengkapi fitur pendukung: riwayat absensi, notifikasi, dan profil karyawan.

  • Hari 8: Attendance History screen dengan chronological list. Filter status (Hadir, Telat, Izin, Alpha). Detail view: lokasi, foto selfie, timestamp. Profile Screen: Employee identity card.
  • Hari 9: Firebase Cloud Messaging (FCM) setup. Push notifications: reminder absensi, success clock-in, GPS/face detection failure. Edit profile & change password.
Pekan 2 - Hari 10-12: Admin Dashboard

👔 Admin Monitoring & KPI Charts

Build admin-only screens untuk HRD monitoring dan laporan.

  • Hari 10: Admin role detection & routing. Admin Dashboard: real-time statistics cards (total attendance, lates, absents hari ini). Employee list view.
  • Hari 11: Map overview: semua karyawan clock-in real-time di peta. KPI charts dengan fl_chart (weekly attendance rate, late trend, hourly distribution).
  • Hari 12: Attendance logs per employee (filter by date range). Export data ke CSV/Excel untuk laporan HRD. Employee management (view detail, edit role).
Pekan 2 - Hari 13-14: Polish & Deployment

✨ Final Polish, Testing & Deployment

Bug fixing, UI polishing, performance optimization, dan preparation untuk submission.

  • Hari 13: Bug fixing dari feedback demo. Performance optimization (image caching, lazy loading). UI consistency check (spacing, colors, typography). Error handling & edge cases.
  • Hari 14: Build APK release (signed). Final testing di device fisik. Dokumentasi: README, User Manual, Technical Docs. Presentation slide. Submit semua deliverables.
Final Demo: Presentasi 10 menit + 5 menit Q&A. Semua anggota kelompok wajib presentasi.

04 - AI Development Guide

Cara Menggunakan AI untuk Development

Kamu diperbolehkan dan dianjurkan menggunakan AI (AI assistant tools) untuk mempercepat development. Berikut panduan penggunaannya.

⚠️

Aturan Penggunaan AI

AI adalah asisten, bukan pengganti pemahaman. Kamu wajib memahami setiap kode yang di-generate AI. Jangan copy-paste tanpa memahami. Jika ditanya saat demo, kamu harus bisa menjelaskan kode milikmu sendiri. Plagiarism murni tanpa pemahaman akan dikenakan sanksi.

Prompt Engineering untuk Flutter

💬 Prompt 1: Setup Project Structure
"Saya membuat aplikasi Flutter Factory Attendance untuk absensi karyawan pabrik. Buatkan folder structure yang mengikuti Clean Architecture dengan pemisahan: data (models, repositories, datasources), domain (entities, usecases, repositories interfaces), presentation (screens, widgets, providers), core (themes, constants, utils). Sertakan juga contoh implementasi BaseRepository pattern untuk Firebase Firestore."
💡Tambahkan konteks spesifik seperti "Factory Attendance" agar AI memahami domain bisnis aplikasimu.
💬 Prompt 2: GPS Validation Logic
"Buatkan class GPSValidator di Flutter yang menggunakan geolocator plugin untuk: 1) Mendapatkan current position user, 2) Menghitung jarak ke kantor (lat: -6.2088, lng: 106.8456) menggunakan Haversine formula, 3) Validasi apakah user berada dalam radius 500 meter, 4) Return status: 'IN_AREA' atau 'OUTSIDE_AREA' dengan jarak dalam meter, 5) Handle permission denied dan location service disabled. Gunakan Dart dengan null safety dan sertakan unit test."
💡Sertakan koordinat spesifik dan requirement teknis (null safety, unit test) untuk hasil yang lebih presisi.
💬 Prompt 3: Face Detection Integration
"Buatkan widget FaceCaptureScreen di Flutter yang menggunakan: camera plugin untuk preview kamera depan, google_mlkit_face_detection untuk mendeteksi wajah. Tampilkan alignment frame overlay di camera preview. Validasi: minimal 1 wajah terdeteksi, maksimal 1 wajah (tolak multiple faces). Deteksi blur dengan analisis sharpness image. Indikator lighting (terlalu gelap / cukup). Tombol capture aktif hanya jika semua validasi passed. Desain dengan tema industrial: Deep Navy (#0B1D3A) dan Safety Orange (#FF6B35)."
💡Tambahkan constraint desain (warna, tema) agar AI generate UI yang konsisten dengan design system.
💬 Prompt 4: Debug & Optimize
"Saya mendapat error berikut saat build Flutter: [INSERT ERROR MESSAGE]. Konteks: Error terjadi saat integrasi Firebase Auth dengan Provider state management. Bagaimana cara debug dan fix error ini? Jelaskan root cause-nya juga agar saya paham."
💡Selalu minta AI menjelaskan root cause, bukan hanya solusi. Ini memastikan kamu belajar, bukan hanya copy-paste.
📝

Cara Bertanya yang Efektif ke AI

1. Berikan konteks lengkap: Jelaskan apa yang sedang kamu bangun, stack yang digunakan, dan error yang dihadapi.
2. Sertakan code snippet: Copy error message dan code terkait (jangan screenshot).
3. Minta penjelasan: "Jelaskan kenapa solusi ini works" bukan hanya "Fix ini".
4. Iteratif: Jika jawaban kurang tepat, berikan feedback dan refine prompt.
5. Verifikasi: Selalu test code yang di-generate AI sebelum di-commit.
